Game Development Workstation

A custom game development toolkit built with C++ and Raylib. It includes a Sprite Editor, Animation Editor, and Level Editor designed to simplify the game development workflow.

Game Development Workstation is a custom game development toolkit I created using C++ and Raylib. The goal of the project was to build my own set of development tools instead of relying entirely on existing game engines or external editors. The workstation includes several custom tools, including a Sprite Editor for creating and editing sprites, an Animation Editor for creating animations, and a Level Editor for designing game levels. The tools also include data-saving and loading functionality so that created assets and levels can be reused across projects. Through this project, I explored game engine architecture, graphics programming, editor development, data management, and game development workflows. The project represents my interest in developing the tools behind games, rather than only creating the games themselves.

GameDevRush

A Unity-based game development simulation where players manage a virtual game studio. Players complete development tasks, manage resources, and use different workstations to produce game assets.

GameDevRush is a Unity-based simulation game designed to introduce players to the basic process of game development through interactive gameplay. The game takes inspiration from workflow-based games such as Overcooked, but replaces cooking tasks with game development activities. Players manage a virtual game studio and complete different development tasks through specialized workstations. These include art, programming, audio, and UI-related activities. Each workstation contains its own mini-game that represents a different part of the development process. The project also includes NPC workers, resource management, production systems, client requests, progression, and Dynamic Difficulty Adjustment (DDA). AI systems were developed using concepts such as Finite State Machines, Behavior Trees, and pathfinding to control NPC workers and enemies.
